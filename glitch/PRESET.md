# glitch（動きのプリセット）

作成: 2026-10-23

> ボタンの文字が、デジタルの信号が乱れるようにずれ、色がちぎれ、ノイズが走る。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | glitch |
| ジャンル | 強調 |
| 質感 | 揺れ |
| 環境 | web |
| 出典 | 丸菱電工 |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- ボタン・見出し・ロゴなど、電気・通信・機械・IT など「デジタルの信号」を扱う案件で、押してほしい箇所に添える
- PC のマウスを乗せたとき（hover）に出す使い方が中心。スマホは hover が無いので、`.is-on` を短く（0.5 秒程度）付けてもよい
- 落ち着いた・やさしい案件、福祉・保育・飲食などの案件には向かない。常時は動かさない（目に刺さる）

## 2. どんな印象を与えるか
- ビリッと走る信号の乱れ。技術的で精密、少し攻めた印象。押したくなる好奇心を引く

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-a / --pf-b` | ピンク紫 / 水色 | 案件の差し色 | 色がちぎれて見える 2 色（文字の上に 2 枚重なる） |
| `--pf-noise-opacity` | 0.55 | 0.3〜0.7 | ノイズの濃さ |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. `<a class="pf-glitch" data-text="ボタンの文字"><span class="pf-noise" aria-hidden="true"></span><span class="pf-t">ボタンの文字</span></a>`（`data-text` と文字を同じにする）
3. `@media (hover: hover)` でマウスを乗せると動く（何も足さなくてよい）。`.is-on` を足しても動く
4. 色（`--pf-a`・`--pf-b`）を案件の変数に渡す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 動かさず、ずれた色・ノイズを出さない（入れてある）
- `data-text` の文字は疑似要素の複製で、文言照合には出ない（検査の対象外）。実際の文言は `.pf-t` の中に 1 回だけ書く
- 色のちぎれは短い時間の演出。文字の可読性（コントラスト）は、動いていない状態で確かめる
- ボタンの上でだけ動くので 2.8 の「出そろい 2 秒」の対象外。常時ではなく、触れたときだけにする
