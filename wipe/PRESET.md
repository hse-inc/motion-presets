# wipe（動きのプリセット）

作成: 2026-10-23

> 事例なしサンプル（基本セット）。色の面が横切って画面を覆い、その裏で場面が入れ替わって、そのまま抜けていく。

## 1. いつ使うか
- ページ（場面）の切り替え、タブ・スライドの入れ替え、オープニングから本編への切り替え
- 親（`.pf-wipe`）に高さを持たせ、場面 2 つ（`.pf-wipe-a` が今の場面・`.pf-wipe-b` が次の場面）を重ねて置く
- 帯の色は `--pf-bar`（デフォルトは kit の `--color-main`）。案件の主色に合わせる

## 2. どんな印象を与えるか
- 色の面が横切って画面を覆い、その裏で場面が入れ替わって、そのまま抜けていく。きっぱりした切り替え

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 900ms | 600〜1200ms | 覆って抜けるまでの全体の長さ（入れ替わりはその中ほど） |
| `--pf-bar` | var(--color-main, #24364f) | 案件の主色 | 面の色 |
| `--pf-delay` | 0ms | 0〜400ms | 動き出すまでの待ち |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. `<div class="pf-wipe">` に高さを持たせ、中に `<div class="pf-wipe-a">`（今の場面）と `<div class="pf-wipe-b">`（次の場面）を置く
3. 出したいときに `.is-on` を足す（swipe.js の出現処理がそのまま使える）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
