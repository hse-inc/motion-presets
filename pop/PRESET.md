# pop（動きのプリセット）

作成: 2026-10-23

> 事例なしサンプル（基本セット）。小さい状態から勢いよく大きく出て、少し行き過ぎてから落ち着く。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | pop |
| ジャンル | 登場 / 強調 |
| 質感 | ポップ |
| 環境 | web |
| 出典 | 事例なし |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- バッジ・ラベル・ボタン・アイコンなど、小さくて目を引かせたい要素
- 親しみ・ポップな案件向け。かしこまった案件では使わない
- 1 画面に何個も同時に出すとうるさい（`--pf-delay` を少しずつずらす）

## 2. どんな印象を与えるか
- 小さい状態から勢いよく大きく出て、少し行き過ぎてから落ち着く。明るく元気な「ぽん」

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 500ms | 350〜700ms | 出て落ち着くまでの長さ |
| `--pf-from` | 0.5 | 0.3〜0.8 | 最初の大きさ（1 が等倍） |
| `--pf-over` | 1.12 | 1.05〜1.25 | 行き過ぎる大きさ。大きいほど弾む |
| `--pf-delay` | 0ms | 0〜600ms | 出るまでの待ち |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. 要素に `class="pf-pop"` を付ける
3. 出したいときに `.is-on` を足す（swipe.js の出現処理がそのまま使える）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
- `transform` / `translate` / `rotate` を使う。同じ要素に別の動きを重ねるときは、親子で要素を分ける（float・sway は個別プロパティなので `transform` の出現とは重ねられる）
