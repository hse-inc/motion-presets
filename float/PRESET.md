作成: 2026-10-23

> kit 基本セット（v2.9）。空気中に浮かぶように、上下 6px・傾き ±1.5°・3.6 秒で常にふわふわ往復する。

## 1. いつ使うか
- イラスト・キャラクター・アイコンなど、背景に載せる絵に常時の命を足したいとき（出るときに pop などで弾ませ、そのあと float）
- AGENTS.md 2.8「ポップな出方と常時のふわふわ」の数値（上下 6px・±1.5°・3.6 秒・往復）がそのままデフォルト
- 文章には使わない（読みにくくなる）

## 2. どんな印象を与えるか
- 空気中に浮かぶように、上下 6px・傾き ±1.5°・3.6 秒で常にふわふわ往復する。軽やかで柔らかい

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 3.6s | 2.4〜5s | 片道（上から下）の長さ |
| `--pf-amp` | 6px | 3〜10px | 上下の幅 |
| `--pf-tilt` | 1.5deg | 0.5〜3deg | 傾きの振れ（−tilt〜＋tilt） |
| `--pf-delay` | 0ms | 0〜1200ms | 浮き始めるまでの待ち（出る動きのあとに足すなら出る長さ分） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. 要素に `class="pf-float"` を付ける
3. 動かしたいときに `.is-on` を足す（足している間、動き続ける）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
- 常時動く飾りは、読ませる文章の近くに置かない。同時に動かす数を絞る
- `transform` / `translate` / `rotate` を使う。同じ要素に別の動きを重ねるときは、親子で要素を分ける（float・sway は個別プロパティなので `transform` の出現とは重ねられる）
