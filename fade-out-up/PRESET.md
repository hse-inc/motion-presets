# fade-out-up（動きのプリセット）

作成: 2026-10-23

> 事例なしサンプル（基本セット）。上へ少し持ち上がりながら静かに消える。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | fade-out-up |
| ジャンル | 退場 |
| 質感 | フェード / スライド |
| 環境 | web |
| 出典 | 事例なし |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- ローディング表示・お知らせ・オープニングの文字など、役目を終えて消す要素
- `.is-on` を足すと消える（他のプリセットと逆で、.is-on＝退場）
- 消えたあとは `pointer-events: none` になるが、場所は残る。レイアウトごと消すなら JS で `hidden` を足す

## 2. どんな印象を与えるか
- 上へ少し持ち上がりながら静かに消える。fade-up の逆再生のような、控えめな退場

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 500ms | 300〜700ms | 消える長さ |
| `--pf-rise` | 24px | 12〜48px | 上への移動量 |
| `--pf-delay` | 0ms | 0〜2000ms | 消え始めるまでの待ち（表示しておく時間） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. 要素に `class="pf-fade-out-up"` を付ける
3. 消したいときに `.is-on` を足す（このプリセットだけ `.is-on`＝退場）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
