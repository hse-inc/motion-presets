# fade-up（動きのプリセット）

作成: 2026-10-23

> 出現の標準の動き（`.rv` → `.is-on`）を、名前で呼べるようにしたもの。見た目・秒数は base/base.css と同じ。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | fade-up |
| ジャンル | 登場 |

| 環境 | web |
| 出典 | アステップ |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 本文・写真・カードなど、ページに入ったときに下から静かに出したい要素すべて（標準の出現）
- 強い個性を出したい見出しには使わない（word-drop など別のプリセットにする）

## 2. どんな印象を与えるか
- 下から静かに浮かび上がる、落ち着いた標準の出方。主張せず、読ませる

## 3. パラメータ
> 土台の tokens.css の `--rise`・`--dur-in` と同じ値がデフォルト。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 600ms | 300〜800ms | 出る長さ。長いと「待ち」になる |
| `--pf-rise` | 32px | 12〜48px | 下からの移動量。大きいほど勢いが出る |
| `--pf-delay` | 0ms | 0〜600ms | 出るまでの待ち（上から順に出すとき 120ms ずつ足す） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（土台の `.rv` と併用する場合は、どちらか一方にそろえる）
2. 出したい要素に `class="pf-fade-up"` を付ける
3. 出すときに `.is-on` を足す（swipe.js の出現処理がそのまま使える）
4. 順に出すなら `style="--pf-delay: 120ms"` のように要素ごとに足す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさず最初から表示する（入れてある）
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページ 2 秒以内。`--pf-delay` を積みすぎない
- 待ち（`--pf-delay`）は `.is-on` 側にだけ効かせてある（両方向に効く待ちは `check_css.py --strict` で不合格）
