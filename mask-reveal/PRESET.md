# mask-reveal（動きのプリセット）

作成: 2026-10-23

> 事例なしサンプル（基本セット）。色の帯が左から右へ払うように通り過ぎ、そのあとに中身が現れる。

| 項目 | 値 |

| 名前 | mask-reveal |
| ジャンル | 登場 |

| 環境 | web |
| 出典 | 事例なし |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 短い見出し・ラベル・写真など、「ここから始まる」と切り替えを見せたい要素
- 帯の色は `--pf-bar`（デフォルトは kit の `--color-accent`）。案件の強調色に合わせる
- 長い文章には使わない（帯が通るあいだ読めない）

## 2. どんな印象を与えるか
- 色の帯が左から右へ払うように通り過ぎ、そのあとに中身が現れる。切れ味があり、編集的

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 700ms | 500〜1000ms | 帯が通って中身が現れるまでの長さ |
| `--pf-bar` | var(--color-accent, #e8792f) | 案件の強調色 | 帯の色 |
| `--pf-delay` | 0ms | 0〜400ms | 動き出すまでの待ち |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. `<div class="pf-mask-reveal"><span>中身</span></div>` の形にする（中身は直下の子）
3. 出したいときに `.is-on` を足す（swipe.js の出現処理がそのまま使える）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
