# ripple（動きのプリセット）

作成: 2026-10-23

> 丸い要素のまわりに、輪が静かに広がっては消える。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | ripple |
| ジャンル | ループ / 強調 |
| 質感 | 波紋 |
| 環境 | web |
| 出典 | メタメディア |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 人物の顔写真・担当者アイコン・マイクなど、「ここに人がいる」「ここを見て」と気づかせたい丸い要素
- 押してほしい丸いボタンの周り（常時の注意喚起）
- 四角いカードや文章の塊には向かない（`border-radius: inherit` で形を追う。丸い要素が一番きれい）

## 2. どんな印象を与えるか
- 声や気配が広がるような、やわらかく静かな存在感。派手ではないので連続して置いても疲れない

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 2.4s | 1.6〜3.2s | 輪が 1 回広がって消えるまで |
| `--pf-delay` | 600ms | 0〜1200ms | 最初の輪が出るまでの待ち（.is-on 側だけに効く）。2 本目の輪は半周期ずれる |
| `--pf-spread` | 1.25 | 1.15〜1.6 | 最終の大きさの倍率 |
| `--pf-ring / --pf-ring-2` | 紫・淡い紫 | 案件の色 | 輪の色（手前・後ろ） |
| `--pf-width` | 2px | 1〜3px | 輪の線の太さ |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 丸い要素に `class="pf-ripple"` を付ける（`border-radius` は要素側で付ける）
3. 出すときに `.is-on` を足す
4. 色を案件の変数に渡す（例: `style="--pf-ring: var(--color-key)"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 輪を出さない（入れてある）
- 輪が要素の外へ広がるので、親に `overflow: hidden` があると切れる。広がりは `--pf-spread` で抑える
- 輪は ::before / ::after で描いているため、要素自身の ::before / ::after と同時には使えない
