# spin-pop（動きのプリセット）

作成: 2026-10-23

> 丸いアイコンが、回りながらぽんと大きく出て、少し行き過ぎてから収まる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | spin-pop |
| ジャンル | 登場 / 強調 |
| 質感 | ポップ |
| 環境 | web |
| 出典 | メタメディア |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 3 つの道・3 つの特徴など、アイコンを並べて見せるカードの頭（丸いアイコン・番号の円）
- 小さな要素で遊びを足したいとき。大きな写真・見出しには使わない（回転が目立ちすぎる）

## 2. どんな印象を与えるか
- くるっと回って弾む、軽快で楽しい出方。技術系・クリエイティブ系の案件でも堅くならない

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 600ms | 400〜800ms | 回りながら出て収まるまで |
| `--pf-delay` | 0ms | 0〜500ms | 出るまでの待ち（並べるときは 140ms ずつ足す。.is-on 側だけに効く） |
| `--pf-turn` | -120deg | -180〜-60deg | 出始めの回転角。マイナスで時計回りに回って入る |
| `--pf-ease` | cubic-bezier(0.34, 1.8, 0.5, 1) | 1.4〜2.0 | 行き過ぎの強さ（y1 の値） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. アイコンの要素に `class="pf-spin-pop"` を付ける
3. 出すときに `.is-on` を足す
4. 複数並べるときは `style="--pf-delay: 140ms"` を順に足す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 動かさず最初から表示する（入れてある）
- transform を使うので、同じ要素の別の transform とは同時に使わない（親子で分ける）
- AGENTS.md 2.8: 3 つ並べて 140ms ずつずらすと、最後が約 0.9 秒で出そろう
