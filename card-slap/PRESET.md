## 1. いつ使うか
- 枠線・ベタ影のあるカード（吹き出し・メモ・シール風の面）を出すとき
- 影のない面・写真だけの要素には効果が出にくい（fade-up などにする）

## 2. どんな印象を与えるか
- 大きめの状態から傾いて「ぺたっ」と貼られ、影がぎゅっと縮む。シールやメモを貼った手触り

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 560ms | 400〜800ms | 貼られるまでの長さ |
| `--pf-delay` | 380ms | 0〜600ms | 動き出すまでの待ち（見出しのあとに出す想定） |
| `--pf-from-scale` | 1.22 | 1.1〜1.4 | 最初の大きさ（大きいほど勢いよく貼る） |
| `--pf-from-rotate` | 5deg | 2〜8deg | 最初の傾き |
| `--pf-ink` | #1a1a2e | 案件の文字色 | 着地後の影の色 |
| `--pf-shadow` | 4px 5px 0 | 3px 4px 0〜6px 7px 0 | 着地後の影の大きさ（色は含めない） |

> 青空交通の元の値は、影の色が案件の濃い紺（oklch）。案件側では `--pf-ink` に案件の文字色を渡す。

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. カードに `class="pf-card-slap"` を付ける（枠線・背景は案件側で書く）
3. 出すときに `.is-on` を足す
4. カードを続けて出すなら `style="--pf-delay: 560ms"` のように 2 枚目以降の待ちを足す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 動かさず最初から表示する（入れてある）
- AGENTS.md 2.8: 出そろい 2 秒以内。待ち 380ms + 560ms で約 0.94 秒。カードを 3 枚以上続けるなら待ちを詰める
- 影は box-shadow を動かす。重い飾りを多数並べる画面では枚数を絞る
- 待ちは `.is-on` 側にだけ書いてある
