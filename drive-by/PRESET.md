# drive-by（動きのプリセット）

作成: 2026-10-23

> 町や島の絵の上を、バス・車・人が横切って走り抜け続ける。走りながら小刻みに揺れる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | drive-by |
| ジャンル | ループ |
| 質感 | 流れ |
| 環境 | web |
| 出典 | 青空交通 |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 町・島・道などの背景イラストの上に、乗り物や人の小さな絵を重ねて「生きている場所」を見せたい 1 ページ目・紹介のページ
- 乗り物・人・動物など、横に移動するモチーフの絵があるとき（交通・観光・地域の案件に向く）
- 背景が写真のときは向かない（絵が浮く）。1 ページに 2〜3 台まで

## 2. どんな印象を与えるか
- 町が実際に動いているような賑わいと、楽しい生活感。止まった絵に命が入る

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-x0 / --pf-x1` | -30% / 110% | 画面の外から外へ | 出発位置と到着位置（親の幅に対する割合）。右→左に走らせるなら x0 に 110%・x1 に -30%（絵は `.pf-flip` で向きをそろえる） |
| `--pf-t` | 8s | 3〜10s | 端から端まで走る時間。短いほど速い |
| `--pf-d` | 0s | 負の値で途中から | 走り始めの時間差。負の値にすると最初から画面の途中にいる（複数台を散らすのに使う） |
| `--pf-b / --pf-w` | 8% / 28% | 絵に合わせる | 下からの位置と幅（親に対する割合） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 背景の絵を入れる親に `class="pf-drive-by"`（`position: relative` と高さを持たせる）
3. 動かす絵を `<span class="pf-v" style="--pf-x0:…;--pf-x1:…;--pf-t:…;--pf-d:…">` で包んで置く。左向きの絵を右へ走らせるときは `.pf-flip` を足す
4. ページに入ったら親に `.is-on` を足す（ページが外れたら外して止める）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 走らせず、画面の中ほどに止めて表示する（入れてある）
- 位置を `left` で動かす（原作の作り）。数台までなら問題ないが、数十個は置かない。動く絵は `pointer-events: none`
- AGENTS.md の検査: 動く絵が文字と重なると ✕ になる。背景側（文字の後ろ・上）に置くか、絵に `data-bleed` を付ける
- 見える間だけ動かす。親のページが画面から外れたら `.is-on` を外す（動き続けると電池を使う）
