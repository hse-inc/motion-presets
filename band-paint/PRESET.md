# band-paint（動きのプリセット）

作成: 2026-10-23

> 文字の後ろの色の帯が左から塗られていき、見出しの一文が「決まる」。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | band-paint |
| ジャンル | 登場 / 強調 |
| 質感 | ワイプ |
| 環境 | web |
| 出典 | 青空交通 |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 締めの一文・キャッチなど、1 行の大きな言葉を強く見せたいページの終わり（ページに 1 か所）
- 帯の上でも地の上でも文字が読める配色のとき。stamp と組み合わせると、帯が塗られた上に文字が「ドン」と乗る

## 2. どんな印象を与えるか
- ペンキを引く、ラベルを貼るような手触りで、一文に重みが出る。力強く元気

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 520ms | 350〜800ms | 帯が左端から右端まで塗られる長さ |
| `--pf-delay` | 0ms | 0〜800ms | 塗り始めるまでの待ち（.is-on 側だけに効く） |
| `--pf-band` | エメラルド | 案件のキーカラー | 帯の色 |
| `--pf-ease` | cubic-bezier(0.65, 0, 0.35, 1) | — | 塗られる勢い |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. `<span class="pf-band-paint"><span>文字</span></span>` の形にする（文字の色は帯の上で読める色にする）
3. ページに入ったら `.is-on` を足す
4. 文字も動かしたいときは、子の文字に stamp など別のプリセットを重ねる
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 帯を最初から全部塗って表示する（入れてある）
- 文字は最初から見えている。帯の上でも地の上でも読める文字色にする（コントラスト 大きい文字 3:1 以上を、帯の上・地の上の両方で確認する）
- inline-block。行が折り返す長さのときは帯が長方形のまま折り返し位置で切れる。1 行で収まる短い文向き
