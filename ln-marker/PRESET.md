# ln-marker（動きのプリセット）

作成: 2026-10-23

> カードの中の本文が、行ごとに走るマーカーに拭われるように現れる。マーカーが通り過ぎる途中で文字が見え、マーカーは右へ抜けて消える。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | ln-marker |
| ジャンル | 登場 / 強調 |
| 質感 | ワイプ |
| 環境 | web |
| 出典 | 青空交通 |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- カードや吹き出しの中の短い本文（2〜4 行）を、1 行ずつリズムよく読ませたいとき
- 見出しや大きな 1 行には向かない（マーカーの帯が大きくなる）。本文が長い（5 行を超える）ページでは出そろいが遅くなるので使わない

## 2. どんな印象を与えるか
- 蛍光ペンを引くように行が現れ、1 行ずつ読ませるテンポが生まれる。元気で軽快、手作り感がある

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 600ms | 400〜800ms | マーカーが 1 行を通り過ぎるまで |
| `--pf-step` | 110ms | 70〜180ms | 行と行の時間差 |
| `--pf-delay` | 600ms | 0〜800ms | 最初の行が始まるまでの待ち（.is-on 側だけに効く） |
| `--pf-bar` | エメラルド | 案件のキーカラー | マーカーの色 |
| `--pf-ink` | 濃紺 | 本文の色 | 現れた文字の色（背景に対して 4.5:1 以上） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 本文を `<span class="pf-ln" style="--c:0">…</span>` で 1 行ずつに区切る（`--c` は 0 から順に）。親に `class="pf-ln-marker"` を付ける
3. ページに入ったら親に `.is-on` を足す
4. 色（`--pf-bar`・`--pf-ink`）を案件の変数に渡す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: マーカーを出さず、最初から文字を表示する（入れてある）
- 文字は最初「透明」から始める作り（マーカーが通る途中で色が入る）。動きが止まる環境（reduced-motion・JS 無効で `.is-on` が付かない場合）でも読めるよう、`.is-on` が付かないときの表示は案件側で確認する
- AGENTS.md 2.8: 3 行・既定で出そろいは約 1.5 秒。行数が多いときは `--pf-step` を詰める
- 行は `display: block`。文言の行ごとの区切りは `.ln` と同じ流儀（改行の `<br>` は入れない）
