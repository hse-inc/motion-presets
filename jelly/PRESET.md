# jelly（動きのプリセット）

作成: 2026-10-23

> 興和通信建設で使った動き。縦横に潰れたり伸びたりしながら揺れて静まる、ゼリーのような弾力。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | jelly |
| ジャンル | 強調 |
| 質感 | ぷよぷよ |
| 環境 | web |
| 出典 | 興和通信建設 |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- すでに表示されている語・ボタン・イラストを「ここ」と強調したいとき（タップ時・見出しが出た直後など）
- `.is-on` を付けた瞬間に 1 回だけ動く。出現は別のプリセットで行い、そのあと jelly を足す
- 常時くり返すとうるさい。回数を絞る

## 2. どんな印象を与えるか
- 縦横に潰れたり伸びたりしながら揺れて静まる、ゼリーのような弾力。目を引き、親しみが出る

## 3. パラメータ
> 土台の tokens.css に合わせて、案件側で推奨レンジ内に調整する。
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 800ms | 500〜1100ms | 揺れが静まるまでの長さ |
| `--pf-power` | 1 | 0.5〜1.5 | 潰れ・伸びの強さ（1 が標準。大きいほど大きく変形） |
| `--pf-delay` | 0ms | 0〜400ms | 動き出すまでの待ち |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む（`tools/apply_preset.sh` で複製と `<link>` の追加ができる）
2. 要素に `class="pf-jelly"` を付ける
3. 強調したいときに `.is-on` を足す（1 回動く。くり返すなら class を付け外しする）
4. 案件に合わせて `--pf-*` を調整する（例: `style="--pf-dur: 500ms"`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: `prefers-reduced-motion: reduce` では動かさない指定を `web/preset.css` に入れてある。外さない
- AGENTS.md 2.8: 最初の動き出し 0.3 秒以内・1 ページの出そろい 2 秒以内。`--pf-delay` と `--pf-dur` を足して収まるようにする（待ちは `.is-on` 側にだけ書いてある）
- `transform` / `translate` / `rotate` を使う。同じ要素に別の動きを重ねるときは、親子で要素を分ける（float・sway は個別プロパティなので `transform` の出現とは重ねられる）
