# marquee（動きのプリセット）

作成: 2026-10-23

> 大きな英字の帯が、地の上を横へ流れ続ける。輪郭だけの文字にすると、背景に馴染ませつつ動きの賑わいを足せる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | marquee |
| ジャンル | ループ |
| 質感 | 流れ |
| 環境 | web |
| 出典 | FUKURU |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- PC の左右の余白（レール）・ヒーローの背景など、文字を読ませない面で「動いている」雰囲気を作りたいとき
- 長いページで写真や図が少ない面を、賑やかにしたいとき。社名・英語のキャッチを大きく繰り返す
- 本文・見出しの後ろには置かない（読みづらい）。同じページで 2 本（逆向き）まで

## 2. どんな印象を与えるか
- 止まらずに流れる大きな文字が、勢いと賑わいを出す。輪郭にして薄くすると、うるさくならず「背景が動いている」ように見える

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-speed` | 48s | 20〜60s | 1 周の長さ。大きな文字はゆっくりでも十分に動いて見える |
| `--pf-size` | 120px | 60〜160px | 文字の大きさ |
| `--pf-color` | 濃紺 | 案件の色 | 塗りまたは輪郭の色 |
| `--pf-opacity` | 0.32 | 0.15〜0.5 | 全体の濃さ（背景に馴染ませる） |
| `.pf-marquee--outline / --rev` | 塗り・右から左 | — | 輪郭文字にする／逆向きにする |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 帯の親に `class="pf-marquee"`、中の `.pf-track` に **同じ文字列の組を 2 つ**並べる（半分ちょうどで 1 周になる）
3. 英字の文字列は区切り（`・` など）を入れ、1 組で画面幅より長くする
4. 出すときに `.is-on` を足す。輪郭にするなら `.pf-marquee--outline`
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 流さず静止表示する（入れてある）
- 帯の位置と高さは親側で決める。文字が本文と重なる位置に置くと、検査で重なりが ✕ になる。飾りには `aria-hidden="true"` を付ける
- 輪郭の英字は、全体で 1〜2 か所まで（鈴興建設で、輪郭文字を毎ページに置いて「使いすぎ」と言われた教訓）。塗りの薄い大きな英字なら、もう少し置いてよい
- 見えない間は止める（親が画面から外れたら `.is-on` を外す）
