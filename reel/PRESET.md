# reel（動きのプリセット）

作成: 2026-10-23

> 写真の帯が、止まらず横へ流れ続ける。2 段にして向きを逆にもできる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | reel |
| ジャンル | ループ |
| 質感 | 流れ |
| 環境 | web |
| 出典 | メタメディア |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 雰囲気・人・現場の写真を、文字を載せずにたくさん見せたいページ（特徴・社風・仕事内容）
- 写真が主役の 1 ページに 1〜2 本まで（3 本以上は散漫になる）
- 写真が 1 枚しかない・写真の中身を読ませたい場面には使わない（流れて読めない）

## 2. どんな印象を与えるか
- 写真が次々に通り過ぎ、「人や現場がたくさんある」賑わいと動きが出る。止まって見えない速さにすると生き生きする

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-h` | 6.5em | 5〜10em | 帯の高さ。写真の幅は高さ × 4/3 で決まる |
| `--pf-speed` | 16s | 帯の半分の長さ ÷ 秒数 ≧ 25px/秒 | 1 周の秒数。短いほど速い。写真の枚数・大きさで変わるので px/秒で決める |
| `--pf-gap` | 10px | 6〜16px | 写真と写真の間 |
| `.pf-reel--ltr`（クラス） | 右から左 | `.pf-reel--ltr` で左から右 | 2 段にするときは 2 本目だけ逆向きにする |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. `<div class="pf-reel"><div class="pf-track">` の中に、写真（`<img class="pf-img" width="640" height="480">`）を 1 周ぶん並べ、**同じ並びをもう 1 組続けて**置く（半分ちょうどで 1 周になる）
3. ページに入ったら `.pf-reel` に `.is-on` を足す（案件のページ切り替えの合図に合わせる）
4. 案件のページが画面から外れたら `animation-play-state: paused` にしてもよい（見えない間は止める）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 流れを止めて先頭から静止表示する（入れてある）
- 速さは px/秒で決める（AGENTS.md 2.8）。1 周が 38 秒（約 11px/秒）で「止まって見える」と言われた。約 25〜30px/秒以上にする
- 写真の幅は読み込み前から CSS で決める。デモは同じ並びを 2 組置くだけで動くが、案件では写真の読み込み（decode）後に 1 周の長さを px で測って入れる方式（`--reel-dist`）も使われている。画面の大きさが変わったら測り直す
- 帯が親の外まで続く飾りと検査に数えられることがある。流れる帯は `data-bleed` を付ける（AGENTS.md 手順 7 の宣言）
