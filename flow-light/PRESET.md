# flow-light（動きのプリセット）

作成: 2026-10-23

> 縦の線が上から伸びて、その上を光が上から下へ流れ続ける。「つながっている・流れている」を見せる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | flow-light |
| ジャンル | ループ |
| 質感 | 光 / 流れ |
| 環境 | web |
| 出典 | メタメディア |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 悩み → 解決、応募 → 入社など、縦に並べた項目が順につながっている図（縦の流れ図・番号リスト）
- 1 ページに 1 本まで。ほかの常時の動き（reel など）と同時に置くときは光の方を控えめにする

## 2. どんな印象を与えるか
- 光が一筋、項目を結んで走る。先へ進む流れ・テンポのよさが出る。線が引かれるところから始まるので「描かれていく」印象も加わる

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 1.8s | 1.2〜2.6s | 光が上から下まで走る 1 回の長さ |
| `--pf-delay` | 960ms | 300〜1200ms | 光が走り始めるまでの待ち（.is-on 側だけに効く。線が伸び終わるころ） |
| `--pf-x / --pf-top / --pf-bottom` | 1.05em / 1em / 1.2em | 図に合わせる | 線の左位置と、上下の余白（最初と最後の項目の中心に合わせる） |
| `--pf-line-w / --pf-light-w` | 2px / 4px | 1〜3px / 3〜6px | 線と光の太さ |
| `--pf-line / --pf-light` | 紫・白 | 案件の色 | 線の色・光の色（光は背景に対して明るい色） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 縦に項目が並ぶ親（`<ol>` など）に `class="pf-flow-light"` を付ける
3. 項目は線より前に出るよう `position: relative` を付ける（線は ::before、光は ::after）
4. 出すときに `.is-on` を足す
5. 線の位置は `--pf-x` / `--pf-top` / `--pf-bottom` で項目の中心に合わせる
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 線は最初から全部引き、光は出さない（入れてある）
- AGENTS.md 2.8: 待ちは `.is-on` 側だけ。線 300ms ＋ 伸びる 660ms のあとに光（既定の待ち 960ms）が走るので、出そろいは 2 秒以内に収まる
- 親の ::before / ::after を使うため、親に別の ::before / ::after があると衝突する。そのときは線用の子要素に付け替える
