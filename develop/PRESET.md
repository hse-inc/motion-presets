# develop（動きのプリセット）

作成: 2026-10-23

> 写真が、白く飛んでぼやけた状態から、フィルムが現像されるように色と形を取り戻して現れる。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | develop |
| ジャンル | 登場 |
| 質感 | 現像 / フェード |
| 環境 | web |
| 出典 | PELLICULE |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 写真・イラストを、フィルム・撮影・思い出・記録といった題材のページで見せたいとき（カメラ・写真・映像の案件に向く）
- 写真の 1 枚に絞る。何枚も同時にやると重く、見せ場が散る

## 2. どんな印象を与えるか
- シャッターを切った写真が焼き付いていくような、静かで気持ちのいい驚き。「瞬間を残す」意味を動きで語れる

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 2200ms | 1400〜2600ms | 現像が終わるまでの長さ |
| `--pf-delay` | 0ms | 0〜1200ms | 始まるまでの待ち（.is-on 側だけに効く） |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 写真の要素（`<img>` でも、画像を入れた div でもよい）に `class="pf-develop"` を付ける
3. ページに入ったら `.is-on` を足す
4. 強さを変えるときは `@keyframes pf-develop` の brightness / contrast / blur を案件の CSS 側でコピーして調整する
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: フィルターを外して最初から表示する（入れてある）
- `filter` は描画が重い。1 ページで同時にかけるのは 1〜3 枚まで。大きな写真全面にかけるときは実機で確認する
- AGENTS.md 2.8: 動き出しは 0.3 秒以内・出そろいは 2 秒以内。既定の 2200ms は少し超えるので、`--pf-dur` を 1800ms 程度に縮める（見本は 1800ms）
- blur を使うので、写真の端が一瞬にじむ。親に `overflow: hidden` と角丸があるとにじみが切れて自然
