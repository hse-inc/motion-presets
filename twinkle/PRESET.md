# twinkle（動きのプリセット）

作成: 2026-10-23

> 星形の光が、小さく透明な状態から大きく光って回り、消える。数個を散らすと、きらきらと瞬く。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | twinkle |
| ジャンル | ループ / 強調 |
| 質感 | きらめき |
| 環境 | web |
| 出典 | メタメディア |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 見出しや主役の絵のまわりに、きらめきを数個だけ散らして華やかさを足したいとき（放射の先・見出しの角・ロゴのそば）
- 暗い地・濃い色の地の上が映える。白地には色を濃くする
- 1 ページに 3〜7 個まで。本文の上には置かない（文字に重なる）

## 2. どんな印象を与えるか
- 宝石や星が光るような、明るく華やかな瞬き。待ちをばらすと、同時に光らず自然に見える

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 2.2s | 1.6〜3.2s | 消えて光って消えるまでの 1 周期 |
| `--pf-delay` | 0s | 0〜2s（星ごとにばらす） | 最初に光るまでの待ち。星ごとに変えて散らす（.is-on 側だけに効く） |
| `--pf-size` | 14px | 10〜36px | 星の大きさ |
| `--pf-color` | 金色 | 案件の差し色 | 星の色 |
| `--pf-turn` | 45deg | 0〜90deg | 光ったときの回転 |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 飾りの `<span class="pf-twinkle">` を数個置き、位置は `left` / `top`（親は `position: relative`）で決める
3. 星ごとに `--pf-delay`・`--pf-size`・`--pf-color` をばらす（JS で散らしてもよい）
4. ページに入ったら `.is-on` を足す
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 動かさず、淡く表示したままにする（入れてある）
- 飾りなので `aria-hidden="true"` を付ける。文言照合の対象外にする
- AGENTS.md の検査: 飾りが文字と重なると ✕ になる。重ねない位置に置くか、飾りに `data-bleed` を付ける
- 1 つずつ要素にするので、数十個は置かない（重くなる）
