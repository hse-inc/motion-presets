# iris（動きのプリセット）

作成: 2026-10-23

> 次の写真が、ある一点から円形に広がって、今の写真を覆っていく。

## 0. 分類
| 項目 | 値 |
|---|---|
| 名前 | iris |
| ジャンル | 登場 / 遷移 |
| 質感 | ワイプ / ズーム |
| 環境 | web |
| 出典 | FUKURU |
| 追加日 | 2026-10-23 |

## 1. いつ使うか
- 最初のページ（キービジュアル）で、数枚の全面写真を切り替えるとき（次の写真が角から開く）
- 写真の差し替え・ビフォーアフター・場面の切り替えなど、「次が開く」ことを見せたいとき
- 写真の切り替えが 1 回きりのページ。連続して何度も切り替える画面では、間隔を 3 秒以上あける

## 2. どんな印象を与えるか
- カメラの絞り（アイリス）が開くような、軽快で切れのいい場面転換。丸く広がる形が親しみやすく、柔らかい

## 3. パラメータ
| 変数名 | デフォルト | 推奨レンジ | 効き方 |
|---|---|---|---|
| `--pf-dur` | 900ms | 600〜1200ms | 円が広がりきるまで |
| `--pf-delay` | 0ms | 0〜300ms | 始まるまでの待ち（.is-on 側だけに効く） |
| `--pf-x / --pf-y` | 86% / 6% | 0〜100% | 円が広がり始める点。図形・ボタンのある角に合わせる |
| `--pf-ease` | cubic-bezier(0.22, 1, 0.36, 1) | — | 広がる勢い |

## 4. 使い方
1. `web/preset.css` を案件の CSS に取り込む
2. 親（`position: relative; overflow: hidden`）の中に、今の写真の上へ次の写真を重ねる。次の写真に `class="pf-iris"`
3. 切り替えるときに `.is-on` を足す。終わったら次の切り替えのために、新しい写真を下へ、次の写真を上へ入れ替える（JS は案件側）
4. 開始点は `--pf-x`・`--pf-y` で決める（例: 左下から `--pf-x:10%; --pf-y:90%`）
- 見本: `web/demo.html`

## 5. 注意
- reduced-motion: 円を作らず、すぐ切り替える（入れてある）
- clip-path で切り抜くので、親の角丸（`overflow: hidden`）と相性がよい。重ねる写真は同じ大きさにそろえる
- 写真は全面で使うのが前提。小さい写真に使うと円が見えない
- AGENTS.md 2.4: 1 ページ目の動画は素材をそのまま使う（動画のページには使わない）。画像の 1 ページ目（`HERO=image`）の型の一部として使う
